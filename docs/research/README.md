# 調査の置き場

1 テーマ 1 ディレクトリ。名前に日付を付けて、古くなったかを名前で分かるようにする。

```
docs/research/<topic>-<YYYYMMDD>/
├── report.md     # 結論が先。根拠になる文に [n] を付ける
└── sources.md    # 出典の表。[n] はここの行と 1 対 1
```

`sources.md` の形（列はこの順。pre-commit の research-sources が検査する）:

```
| n | 出典 | 種類 | 何を確かめたか | アクセス日 |
|---|---|---|---|---|
| 1 | https://example.com/spec | 一次 | 4.2 節の上限値が 500 であること | 2026-10-02 |
```

- 種類は `一次`（公式・原典）か `二次`（解説・まとめ）。一次を先に並べる
- 何を確かめたかは空にしない。開いて使ったものだけを載せる
- 判断は ADR（docs/adr）に書き、ここからはリンクで引く
